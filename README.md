# 🌐 日本語 ⇄ スペイン語 相互学習Webアプリ (nihongo-espanol-study)

いつでも・どこからでもスマホやPCで学習できる、メキシコ人生徒向け日本語学習（JLPT対策）と、日本人向けスペイン語学習（DELE対策）のWebアプリケーション群です。用途に合わせて2つのハブ（ポータル）に完全に分離されています。
